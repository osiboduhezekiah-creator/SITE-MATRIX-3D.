Welcome to SITE MATRIX 3D 🏗️

🖥️ New layout

  • The ☰ menu (top-left) holds everything: your current project, 🏠 Home (landing page), Project, Edit, Account and Help.
  • Build / Projects (left) and Inspector (right) are floating docks — collapse them with ◀ ▶ for a fullscreen canvas, reopen with the edge tabs.
  • The command dock at the bottom holds Views, Render style, Theme and Spin — swipe it sideways on small screens.

🚀 Build in 3 easy steps

  1. Add blocks — click any block in the left dock library (walls, floors, roofs, doors, windows…).
  2. Move them — click an object to select it, then drag the colored arrows. Switch to Rotate / Scale tools to turn and resize.
  3. Fine-tune — edit exact position, rotation, size and color in the right Inspector dock.

👻 Holographic Studio

  • 🧊 Real — normal render. 👻 Holo — solid wire hologram. 💥 Exploded — parts blast apart (drag the Spread slider). ✨ Volumetric — particle scan with a sweeping plane.
  • Holograms auto-rotate on a glowing pedestal — toggle with ⟳ Spin.
  • The holographic HUD streams live X / Y / Z dimensions, center, bounds, volume and part count.

📁 Projects & activation

  • Demo mode gives you 1 sandbox project with every tool. Subscribe for ₦2,000/month to create unlimited projects of your own, with a thumbnail library and JSON export. Your subscription stays active for 30 days and can be renewed anytime.
  • Use the 📁 Projects tab (left dock) to switch, rename, duplicate and delete projects.

🖱 Camera controls

  • Left-drag orbit  •  Right-drag pan  •  Scroll zoom
  • Click an object to select  •  Double-click to focus  •  Click empty space to deselect
  • Use the Top / Front / Side buttons in the command dock for blueprint-style views.

🔄 Precise rotation & movable taskbar

  • In Select mode, every selected block gets a glowing turntable ring on the ground — drag it left/right to spin the block live (snaps to 15° when Snap is on).
  • ⧉ Duplicate fast: hold Alt and drag any gizmo to drag out a copy, or right-click any block for Duplicate / Focus / Rotate / Delete.
  • 📐 Custom sizes: type any Length × Height × Width in the Building Blocks panel, pick m / cm / mm, then hit Add Custom Block.
  • 🤖 Matrix Assistant: click the 💬 button (bottom-right) to chat with the built-in AI — sizes, unit converter, how-tos, subscription help, and it can even build entire rooms from your instructions. It only answers building questions.
  • Select any block, then use the 🔄 Turntable dial in the Inspector to rotate it to an exact degree — drag the dial in a circle, use the slider, tap presets (0° / 45° / 90° / 180° / 270°), or switch the X / Y / Z axis. The block turns smoothly and live in the workspace.
  • Drag the ⋮⋮ grip on the bottom taskbar to slide it sideways; double-click the grip to re-center it. Its position is remembered.

  • Turn on Snap to grid so walls line up perfectly.
  • Mount doors & windows on walls by moving them against the wall surface.
